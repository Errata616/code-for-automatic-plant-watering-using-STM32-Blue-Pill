# code-for-automatic-plant-watering-using-STM32-Blue-Pill

this is the code for automatic plant watering system using stm32 blue pill. It has 2 modes, the first mode is automatic which will automatically water the plant when it detects dry soil, the second mode is manual mode which will water the plant during specific time of the day, we can also change time so that it will water the plant whenever we want.
